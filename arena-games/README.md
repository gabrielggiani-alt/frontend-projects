# Arena Games

A gaming e-commerce store built with vanilla HTML, CSS and JavaScript. No frameworks, no libraries, no build step.

Browse the catalog, filter by category, search by name, manage a shopping cart with quantity control and stock limits, get an automatic discount and complete a simulated checkout.

## Features

- Product catalog rendered dynamically from JavaScript objects
- Category filter and name search
- Shopping cart: add, remove, change quantity, with stock validation
- Automatic subtotal, discount (10% over R$ 500) and final total
- Object-oriented structure with `Produto` and `Carrinho` classes

## Run

Open `index.html` in any browser.
